# data/eval

Generated by `evaluation/generator/` from `data/pmo-dataset/`, per [`evaluation/METHODOLOGY.md`](../../evaluation/METHODOLOGY.md). Nothing here is hand-written. One directory per version, immutable once a sweep has cited it — different operators, RNG seed, or source snapshot means `v1.1.0`, never an edited `v1.0.0`.

```
v1.x.x/
  manifest.json          version, source snapshot, RNG seed, counts per class,
                         assisting model + prompt version, rejection rate
  seeds/<seed>.bpmn      models that passed the eligibility gate
  descriptions/seeds/    source descriptions for eligible seeds
  variants/<vid>.bpmn    the injected instances — what the sweeps read
  descriptions/variants/ descriptions matched to variant stems
  ground_truth/<vid>.json
  applicability.json    eligible and RNG-selected F01/F02 split-join pairs
  refinement/            M_core + D_extra + M triples (METHODOLOGY §7)
  wild/                  failed the seed gate, with the reason
  malformed/             defects outside the IR vocabulary (duplicate xsd:ID,
                         broken XML) — exercises the import guard, not a tier
  EXCLUSIONS.md
```

`wild/` and `malformed/` ship as part of the dataset. Dropping what the system cannot handle gives a recall computed over inputs selected for being handled.

**Stems must match.** `variants/<vid>.bpmn` and `ground_truth/<vid>.json`, because that is the only join the metrics have — see [`evaluation/README.md`](../../evaluation/README.md). `<vid>` is `<seed>_<operator>_<site>`, e.g. `07_F02_g3`; multi-defect variants join operators with `+`, e.g. `07_F02+M01_g3s2`.

```json
{
  "variant_id": "07_F02_g3",
  "seed": "07",
  "operators": ["F02"],
  "class": "SOUND",
  "expected_finding": "lack_of_synchronisation",
  "expected_elements": ["Gateway_1a2b3c"],
  "injection": [ { "op": "change_gateway_type", "id": "Gateway_1a2b3c", "new_type": "exclusiveGateway" } ],
  "repair": [ { "op": "…" } ],
  "detected_by_construction": true,
  "detected_by": { "tier1": [], "woflan": ["woflan:soundness"] },
  "anchor": null
}
```

`injection` stores the exact `EditOp` applied to the seed, and `repair` stores its inverse. `expected_finding` comes from the operator's definition, not from running a checker; the checker is under evaluation and cannot be its own oracle. `detected_by` records tier-1 and Woflan findings separately. `detected_by_construction: false` marks instances no tier reports; they stay in and measure the ceiling. `anchor` is `SEM`-only.

`ATTRIBUTION.md` identifies the PMo source, its DOI and CC BY 4.0 license, and the changes made by the generator. `manifest.json` records SHA-256 hashes for every generated or copied file except the manifest itself.

Sibling directories — `rule_cases/`, `test_cases/`, `import_cases/` — are unit-test fixtures, and `.cases/` is the Chapter 6 case study. No thesis number comes from any of them.
